# Inventaire des projets (Static Projects Hub)

Ce projet est un **hub statique de projets** regroupant l’ensemble de mes réalisations issues de différentes formations et expérimentations.

L’objectif est simple :
centraliser tous mes projets dans une seule interface et permettre un accès rapide à leurs versions en ligne via des liens actifs.

Contrairement à un portfolio classique (sélectif), ce site adopte une approche **exhaustive**, en listant tous les projets, qu’ils soient simples exercices ou réalisations plus abouties.

---

## Objectifs

* Centraliser tous mes projets statiques
* Fournir un accès rapide à chaque projet déployé
* Organiser les projets par formation / origine
* Servir d’archive de progression

---

## Stack technique

* HTML5
* CSS3
* JavaScript (vanilla)
* Déploiement : GitHub Pages / Netlify (à adapter selon ton cas)

---

## Fonctionnement

Le site affiche une liste de projets sous forme de sections :

* Chaque section correspond à une formation ou une catégorie
* Chaque projet est représenté par un bouton / tag cliquable
* Chaque bouton redirige vers une version en ligne du projet
